O que eu aprendi

1. Qual forma de utilizar JavaScript escolheria para um código de 200 linhas reutilizado em várias páginas?

Eu escolheria utilizar um arquivo JavaScript externo, porque assim poderia criar o código uma única vez e chamá-lo nas páginas em que fosse necessário. Isso evita repetir o mesmo código em vários arquivos HTML e facilita futuras alterações.

2. Como um componente React ajuda a organizar a repetição de produtos?

Um componente React ajuda a evitar a repetição de código, pois permite criar uma estrutura que pode ser reutilizada para vários produtos. No catálogo da AgroFeira, criamos o componente Produto e utilizamos propriedades para passar o nome de cada item. Dessa forma, conseguimos organizar melhor o código e facilitar alterações futuras.

3. Por que os outros botões não mudavam quando um produto era clicado?

Isso acontece porque utilizamos o useState, que permite controlar o estado de cada botão individualmente. Cada produto possui seu próprio estado, então, quando clicamos no botão do Açaí, somente ele muda para “No carrinho”, enquanto os outros continuam como “Adicionar”.

4. Depois de trabalhar com CSS no React, você mudaria sua escolha de ferramenta de estilização?

Continuo escolhendo o CSS tradicional, já estou familiarizada com ele e considero sua utilização simples. Mudar para outra ferramenta nesse momento seria mais complicado, eu precisaria aprender como ela funciona antes de utilizá-la com confiança.
